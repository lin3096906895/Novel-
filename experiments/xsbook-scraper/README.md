# xsbook 爬虫实验（独立于主项目）

> ⚠️ **免责声明**
>
> 本目录是早期的个人爬虫练习代码，**不属于 `novel-platform` 主项目**，与主项目的采集能力无关。
> 主项目内的正式采集实现位于 `apps/server/src/crawler/`，仅支持公版作品与明确授权的来源。
>
> 本目录中的脚本针对第三方商业小说站点（xsbook.org），会抓取受版权保护的正文内容。
> 请勿用于商业用途、二次分发或任何侵犯他人版权的场景。仅供爬虫技术学习参考，
> 使用者需自行承担全部合规与法律责任。

## 文件说明

| 文件 | 说明 |
| --- | --- |
| `xsbook_crawler.py` | 分类列表采集：演示 `requests.Session` 保持 Cookie、首次请求触发 JS 挑战后二次请求取真实页面 |
| `xsbook_novel.py` | 正文采集：演示搜索、目录解析、`ThreadPoolExecutor` 并发抓取与 TXT 合并 |
| `xclass_1.json` | 列表采集的示例输出（他人版权元数据），仅用于展示数据结构 |

## 技术要点

- 使用持久化 Cookie jar 处理一次性 Cookie 校验
- 并发抓取 + 结果合并（`concurrent.futures`）
- `BeautifulSoup` 解析目录与正文，正则清洗正文

如需从公开仓库中移除此目录，直接删除本文件夹即可，不影响主项目构建。
